AI Fluency build story

From research paper to working example

The first piece of work in my portfolio is a FlyRank study about which pages an editor should review for a search visibility drop. I wanted an ML hiring manager to be able to open the research quickly, see exactly what was measured, and try one small part of the method. I used Codex to help turn the case into a web page and implement the calculation.

The clearest result was the difference between the two review objectives. With ten slots per client, logistic ranking found more qualifying declines. A pooled exposure rule surfaced fewer declines while covering more total lost impressions. Both observations belong in the case because they lead to different decisions.

The checker exposed a useful mistake. In one test, 10,000 impressions fell to 7,001. The result was below the 30% cutoff, but the display rounded the change to 30.0%. The calculation was correct and the explanation was unclear. The checker now labels rounded values and names the threshold it missed. The demo still checks only the outcome rule from two observed counts. It cannot predict the next month’s traffic.

The next case will revisit the ranking client by client and examine where it disagrees with the exposure rule. I want to show whether the average hides a client that would be better served by the simpler baseline.
